# Keyword Search and BM25

Keyword search ranks documents by the words they share with the query. It is fast, needs no model, and is excellent at exact terms such as product names, error codes, and identifiers.

BM25 is the classic keyword ranking function. A term counts for more when it appears often in a document, but with diminishing returns, and for much more when it is rare across the whole collection, which is measured by inverse document frequency.

BM25 also normalises for length, so a long document does not win just because it contains more words. Two constants control this: k1 sets how quickly repeated terms saturate and b sets how strongly length is penalised.

Its weakness is vocabulary mismatch. A query for "car" will not match a document that only says "automobile", and a misspelled word matches nothing at all.
